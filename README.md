# pai-final-box-task

**Physical AI 応用1 最終課題：Gazebo上のロボットアームによる箱の把持・移動・設置**

## 概要

Gazebo上のCrane+ロボットアームで、机上の箱を**把持・持ち上げ**、旋回して別の位置に**設置**した後、アームを**初期姿勢へ戻す**。

## 実行環境

- **OS・実行基盤：** Windows／WSL2／Docker
- **ROS：** ROS 2 Humble
- **シミュレーター：** Gazebo（Ignition Fortress）
- **ロボットモデル：** 講座で使用したCrane+のモデル・関連パッケージ

本リポジトリには、制御用Pythonプログラムを収録している。**実行には、講座の環境とCrane+の関連パッケージが必要である。** 本リポジトリのcloneだけでは、実行環境は構築されない。

## 使用ファイル

| ファイル | 内容 |
| --- | --- |
| `pick_place_box.py` | 箱の把持・持ち上げ・移動・設置を順に実行する制御プログラム |

**把持時の指の目標角度は0.25 radに固定している。**

## 実行方法

以下は、講座のDockerコンテナ内で、Pythonファイルを`/workspace/final_assignment`に配置した場合の実行例である。

### 1. ROS 2の環境を読み込む

**コンテナ内のターミナル**で実行する。

```bash
source /home/ubuntu/pai_ws/install/setup.bash
```

### 2. Gazeboとロボットを起動する

```bash
ros2 launch crane_plus_gazebo crane_plus_with_table.launch.py
```

### 3. Pythonプログラムを実行する

**箱とロボットが初期状態にあることを確認**し、別のコンテナ内ターミナルで実行する。

```bash
source /home/ubuntu/pai_ws/install/setup.bash
python3 /workspace/final_assignment/pick_place_box.py --speed 2
```

> **`--speed 2`について：** プログラム内の指定動作時間を半分にする設定であり、録画した動画の倍速再生ではない。処理待ちなどもあるため、実時間全体が正確に半分になるとは限らない。

## 動作の流れ

1. 箱の方向へアームを旋回する。
2. 指を開き、箱を挟む位置へ接近する。
3. 指を閉じ、箱を持ち上げる。
4. 箱を保持したまま移動先へ旋回する。
5. 箱を下ろして指を開き、机上に設置する。
6. アームを退避させ、初期姿勢へ戻す。

## 工夫した点

- **把持姿勢の調整：** 初期配置でJoint1の目標角度を約−95.2度に補正し、把持時の箱の横滑りを抑えることを図った。
- **箱中心を基準とした位置計算：** Joint1の軸中心から箱中心までの水平距離と方向を用いて、把持位置を計算した。
- **動作時間の調整：** 各動作の指定時間を調整し、一連の動作の短縮を図った。
